# Azevedo Engineering

Fundação v0.1.1 de um engineering harness reutilizável para coding agents.

Esta versão contém contratos, project inspection conservadora, classificação de risco, verification por scope, evidence/waivers vinculados à task e um adapter Codex mínimo. Ela não contém o CLI público, plugin, hooks, MCP ou um catálogo completo de conteúdo.

Consulte [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) para os limites e decisões do projeto.

```bash
pnpm install
pnpm verify
```
